# Contributing to `sk-nodeexpress`

Thank you for taking the time to contribute to `sk-nodeexpress`! We welcome all contributions, bug fixes, features, and documentation improvements.

---

## 🚀 How to Contribute

### 1. Fork & Clone
1. Fork the repository on GitHub: `https://github.com/kumarshobhit-1/create-nodeexpress`
2. Clone your fork locally:
   ```bash
   git clone https://github.com/YOUR_USERNAME/create-nodeexpress.git
   cd create-nodeexpress
   ```

### 2. Local Setup
```bash
npm install
```

### 3. Create a Feature Branch
```bash
git checkout -b feature/my-amazing-feature
```

### 4. Test Changes Locally
To test the CLI locally against a sample project directory:
```bash
node bin/cli.js my-test-app --yes
```

### 5. Commit & Push
Follow conventional commit messages:
- `feat: add Prisma ORM support`
- `fix: handle directory overwrite prompt`
- `docs: update README flags table`

```bash
git commit -m "feat: my change description"
git push origin feature/my-amazing-feature
```

### 6. Open a Pull Request
Submit a Pull Request against the `main` branch of the original repository.
